# CLAUDE.md

All project instructions live in [AGENTS.md](AGENTS.md). Read it first.

Key points:
- This is a Shopify theme. Theme folders must stay at the repo root.
- The `shopify` branch is connected to the Shopify store. Deploy by merging `main` into `shopify`.
- Shopify commits theme-editor changes back to `shopify`, so pull before editing and merge `shopify` back into `main`.
